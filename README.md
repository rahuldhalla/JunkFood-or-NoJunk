# Junk or No

A beginner-friendly **Next.js + TailwindCSS** app where users type a food item and the app classifies it as junk food or not.

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## How it works

- Uses a simple list of junk food and healthy food keywords.
- Matches user input against these keywords.
- Shows one of three outcomes:
  - **Junk Food**
  - **Not Junk Food**
  - **Maybe / Mixed**

This project is intentionally simple to help beginners understand React state, input handling, and conditional UI.
